## 신경망 연산 가속기 구조의 연산 병렬성 향상 방식 제공된 문맥에서 **AI 코어 및 가속기 특허의 신경망 연산 가속기 구조**는 주로 **명령 처리 구조화**, **데이터 슬라이스 단위 처리**, **행렬 연산 병렬화**, **다중 처리 요소 활용**을 통해 연산 효율과 병렬성을 높인다. 첫째, **데이터 처리 장치**는 제어 모듈 안에 **명령 캐시 유닛, 명령 처리 유닛, 저장 큐 유닛**을 두어 인공 신경망 연산과 관련된 계산 명령을 저장하고, 이를 해석해 **복수의 연산 명령**으로 분해한다. 저장 큐는 실행할 연산 명령 또는 계산 명령을 큐 순서에 따라 저장하므로, 신경망 모델 연산 시 명령 흐름을 체계화해 연산 효율을 높이는 구조로 설명된다. 둘째, 컨볼루션 기반 인공지능 가속기 구조에서는 **입력 데이터와 커널 데이터를 각각 별도의 데이터 버퍼에서 수신**하고, 이를 **슬라이스 단위로 이동**시킨다. 입력 데이터는 제1 데이터 버퍼와 2차원 시프트 레지스터를 통해 이동하고, 커널 데이터는 제2 데이터 버퍼와 입력 시프트 레지스터를 통해 전달된다. 이후 곱셈 블록 회로가 입력 데이터 슬라이스와 커널 데이터 슬라이스 사이의 컨볼루션 연산을 수행한다. 즉, 데이터를 작은 슬라이스로 나누고 버퍼·시프트 레지스터를 통해 공급함으로써 컨볼루션 연산을 효율적으로 처리한다. 셋째, 행렬 연산 중심 구조에서는 **N차원 논리 회로 배열**, 입력 데이터 라인, 가중치 행렬 입력 라인, 출력 데이터 라인을 갖춘 장치를 통해 신경망 프로세서에서 신경망 연산을 수행한다. 인공지능은 신경망 구현을 위해 많은 행렬 연산을 필요로 하며, 이러한 계산은 병렬 처리될 수 있기 때문에 특수 행렬 프로세서 회로가 성능 향상에 기여한다. 넷째, 더 직접적인 병렬 연산 구조로는 **처리 요소 배열을 갖는 매트릭스 처리 유닛**이 제시된다. 이 구조는 행렬 곱셈 명령에 따라 다수의 **병렬 fused multiply-accumulate 연산**을 수행하여 결과 행렬을 생성한다. 또한 칩렛 기반 AI 가속기에서는 여러 칩렛, 타일, 슬라이스 및 DIMC 디바이스를 사용해 행렬 계산 처리량을 높이고, 클록 사이클당 다수의 multiply-accumulate 연산을 수행하는 방식이 제시된다. 종합하면, 해당 특허군에서 신경망 연산 가속기 구조는 **연산 명령을 복수 명령으로 분해·큐잉하고, 입력/커널 데이터를 슬라이스 단위로 병렬 공급하며, 논리 회로 배열·처리 요소 배열·칩렛/타일/슬라이스 구조를 통해 행렬 곱셈 및 누산 연산을 동시에 수행하는 방식**으로 연산 병렬성과 처리 효율을 높인다. ### References - [1] 17-511417 - [2] 17-459782 - [4] 18-212648 - [5] 18-493616 - [7] 2020-7036316

관찰 결론과 주의점

1. Patent-100은 LightRAG 안에서 162 chunks, 1596 entities, 2203 relations로 변환됐다.

2. 특허 특화 prompt 적용 후 metadata relation ratio는 0.01로 낮아졌고, technical relation ratio는 0.9401로 높게 유지됐다.

3. 검색 단계에서는 mode별 context가 크게 달라진다. AA-1에서 local은 69 relations, global은 10 relations, hybrid는 36 relations를 사용했다.

4. 답변 평가에서는 GraphRAG global이 강했지만 길이 편향이 남아 있고, LightRAG hybrid는 naive 대비 뚜렷한 우위를 보이지 않았다.

5. 이 보고서는 값 이동 관찰 보고서이며, 수행하지 않은 HyDE/RQ-RAG/5→10→25 누적 실험은 결과를 채우지 않았다.

최종 결론

AI 반도체 특허 100건은 LightRAG 내부에서 단순 텍스트 묶음이 아니라 기술 entity, relation, source chunk, vector record로 분해되어 관찰 가능한 graph-retrieval 구조로 변환됐다.

다만 이 구조가 항상 chunk-only retrieval보다 나은 답변을 만든다고 단정할 수는 없다. 이번 실험의 보수적 결론은 “그래프 구축 품질은 성공했지만, 답변 품질의 이득은 질문 유형과 judge bias를 분리해서 해석해야 한다”이다.
